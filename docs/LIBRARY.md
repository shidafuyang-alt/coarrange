# MusicCraft 作品库

翻唱、改编和创作任务成功后，其混音结果会自动显示在「每个版本，都值得听见」中。已有成功任务也会自动补入，无需再次调用模型。任务元数据和音频来自本机项目的 `.musiccraft-data/`；这是当前项目的共同作品库，不是按登录账号隔离的个人云盘。

## 使用

- 用分类选择全部、我的作品、我的翻唱、我的改编、我的创作或预制示例。
- 每一行支持试听、收藏、下载及移入回收站。显示生成模型与完成时间，方便识别版本。
- 在回收站点击「恢复」可重新加入列表。移走正在播放的作品时会停止播放。
- 真实模型结果面板新增「查看作品库」，成功后会自动刷新列表；也可以手动刷新作品库。
- 用户的作品标题不会被中英翻译改写；分类、按钮和说明支持中英文。

## 作品命名

生成前可填写「作品名称（可选）」。留空时按类型自动编号：`翻唱歌曲1`、`改编歌曲1`、`原创歌曲1`。编号在任务成功后分配并保存；已有成功结果按创建时间补号，列表仍按最新完成的作品在前展示。

点击自己作品旁的铅笔可修改名称，最多 80 个字符。清空名称后保存，会恢复原来的自动编号名称。自定义名称写入任务元数据，不发送给规划或音乐模型。回收站、恢复、改名和服务重启都不会重新编号；自定义命名的成功任务也占用该类型的一个编号。

## 保存与删除的含义

真实结果的回收站状态写入对应任务记录的 `libraryDeletedAt`，应用重启后仍保留。删除在这里表示从活动列表移入回收站，不会永久擦除混音、分轨、参考录音或源素材，也不释放音频占用的磁盘空间。恢复不重新生成或产生模型费用。

预制示例是共享的静态资产。删除示例只在当前浏览器隐藏它，在回收站可恢复；不会破坏风格对比或其他示例功能。收藏也保存在当前浏览器。

静态网页或离线分享文件仍可使用预制示例；读取真实作品需要运行 Node 后台。作品库浏览和播放已有结果不需要 GPU 开机。

## 接口与验证

- `GET /api/library`：列出已成功生成的结果和回收站状态，仅返回标题、模式、时长、模型、时间和音频地址等展示字段；不返回内部 Prompt、歌词或密钥。
- `PATCH /api/library/:id`：通过 `{ "title": "名称" }` 修改名称，空字符串恢复默认名称。
- `DELETE /api/library/:id`：幂等地移入回收站。
- `POST /api/library/:id/restore`：恢复作品。

修改接口保留现有客户端标记和跨站请求检查，只允许管理成功的结果。测试覆盖已有任务补入、三个生成模式、内部字段隔离、重启后的删除与恢复、音频保留、浏览器示例隐藏与恢复，以及生成成功后的自动刷新。

Chrome 中另用独立测试数据完成了播放、删除和恢复操作；没有删除用户的实际作品。
